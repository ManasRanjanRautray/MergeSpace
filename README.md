# MergeSpace

Student social platform — **Connect. Collaborate. Grow.**

## Start locally

1. Copy `backend/.env.example` to `backend/.env` and set `MONGO_URI` and `JWT_SECRET`.
2. Run `npm install` in the root, then `npm run install:all`.
3. Run `npm run dev`.

The API runs at `http://localhost:5000`; the client runs at `http://localhost:5173`.
