MergeSpace 🌐

MergeSpace is a social media dashboard project built as part of my journey into full-stack web development. The goal is to learn how frontend and backend technologies work together to build interactive web applications.

🚀 About the Project

MergeSpace is a learning project focused on developing practical skills in the MERN stack, database integration, and web application development.

🛠️ Technologies Used

- MongoDB – Database
- Express.js – Backend web framework
- React.js – Frontend library
- Node.js – JavaScript runtime
- JavaScript – Application logic
- CSS – Styling

✨ Features

- Social media dashboard interface
- Frontend and backend development practice
- Database connectivity using MongoDB
- REST API development and integration
- Hands-on learning with the MERN stack

Note: Features are subject to the current implementation of the project.

⚙️ Getting Started

1. Clone the repository

git clone https://github.com/ManasRanjanRautray/MergeSpace.git

2. Navigate to the project folder

cd MergeSpace

3. Install dependencies

Install dependencies in the frontend and backend directories according to their respective "package.json" files.

npm install

4. Configure environment variables

Create a ".env" file in the backend directory and configure the required variables.

MONGO_URI=your_mongodb_connection_string
JWT_SECRET=your_secret_key
PORT=5000

Replace the placeholder values with your own configuration. Never commit real credentials or secrets to GitHub.

5. Run the application

Start the frontend and backend using the scripts defined in their respective "package.json" files.
